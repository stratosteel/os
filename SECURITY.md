# Security

Report a vulnerability or an unsafe default by email to martin.peroncik@stratosteel.com with the subject "stratosteel/os security". Do not open a public issue for a vulnerability. We acknowledge within 5 working days.

Scope: this repository (template code, policy, MCP server, fixtures). Out of scope: any company's own instance, tenant or data; those are not in this repository.

Principles the code is held to: credentials never in the repository; reads allowed, writes behind policy; external sends only through the approval and send-record path; append-only ledger; no typographic dashes in ledger lines (integrity check).
